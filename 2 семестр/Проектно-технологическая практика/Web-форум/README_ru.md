# VBaumanke
## ВЕБ-ПРИЛОЖЕНИЕ ФОРУМ
Проект для летней университетской практики в [МГТУ им. Н. Э. Баумана](https://bmstu.ru/).

## Описание
**VBaumanke** — это современная веб-платформа-форум, разработанная в рамках летней практики студентами МГТУ им. Баумана. Проект включает как фронтенд, так и бэкенд компоненты и построен на основе современной архитектуры.

### ОБЩАЯ ИНФОРМАЦИЯ

Приложение представляет собой базовую платформу форума, где пользователи могут регистрироваться, входить в систему, создавать посты и оставлять комментарии. Используются база данных PostgreSQL, бэкенд на FastAPI и статический фронтенд на HTML/CSS/JS.

### ВОЗМОЖНОСТИ

- Регистрация пользователей и аутентификация через JWT  
- Создание, редактирование и удаление постов  
- Система комментариев  
- Статический интерфейс фронтенда  
- Docker-окружение для лёгкого развёртывания  

### ТЕХНОЛОГИИ

**Бэкенд**  
- FastAPI  
- SQLAlchemy  
- JWT аутентификация  
- PostgreSQL  

**Фронтенд**  
- HTML5  
- CSS3  
- JavaScript  

**Дополнительно**  
- Docker  
- Docker Compose  

### СТРУКТУРА ПРОЕКТА
forum/
├── backend/               # Логика бэкенда и маршруты (FastAPI)  
├── frontend/              # Статические файлы (HTML, CSS, JS)  
├── init.sql               # SQL скрипт инициализации  
└── docker-compose.yml     # Конфигурация Docker сервисов

### УСТАНОВКА

1. Убедитесь, что установлены Docker и Docker Compose.  
2. Клонируйте репозиторий.  
3. Соберите и запустите проект:  

```bash
   docker compose up --build -d
```

4. Откройте фронтенд в браузере:  
   http://localhost:5500  

5. Бэкенд API доступен по адресу:  
   http://localhost:8000  

### ОСТАНОВКА ПРОЕКТА
Чтобы остановить сервисы, выполните:  
```bash
   docker compose down
```
